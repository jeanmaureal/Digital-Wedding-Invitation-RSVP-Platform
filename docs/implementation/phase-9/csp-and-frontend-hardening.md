## 2. CSP-Safe Zod v4 `jitless` Boot Configuration (`P9-AC07`)

- **Root Cause Identified:** Production chunk analysis revealed that Zod v4 (`4.6.7`) executes a one-time `new Function("")` probe (`allowsEval`) unless `z.config({ jitless: true })` is set prior to schema compilation. Even though Zod catches `EvalError`, Chromium fires a `securitypolicyviolation` event and console error under `script-src 'self'`.
- **Fix:** [zodConfig.ts](file:///c:/Users/almau/Digital-Wedding-Invitation-RSVP-Platform/src/lib/validation/zodConfig.ts) configures `z.config({ jitless: true })` idempotently and is imported first in [main.tsx](file:///c:/Users/almau/Digital-Wedding-Invitation-RSVP-Platform/src/main.tsx), [env.ts](file:///c:/Users/almau/Digital-Wedding-Invitation-RSVP-Platform/src/lib/validation/env.ts), and [setup.ts](file:///c:/Users/almau/Digital-Wedding-Invitation-RSVP-Platform/src/test/setup.ts), enabling strict `script-src 'self'` with `0` `'unsafe-eval'`, `0` `'unsafe-inline'`, and `0` CSP violation events.
